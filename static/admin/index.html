Disponibilidad de Equipos

Reportes, orden de equipos, edición de equipos y categorías

Android iPhone PWA (Web App)

Clave de acceso

Ingresa la clave de API del servidor. Se guarda solo en este navegador.

Orden de equipos

Selecciona el proyecto y mueve los equipos con las flechas. El orden se guarda en el servidor y se refleja en la app.

    Editar equipos

    Selecciona el proyecto, cambia la categoría (acarreo, barrenación, rezagado, vehículo utilitario, etc.), nombre, ECO, estado u observaciones y guarda.

      Administrar categorías

      Agrega, renombra o elimina categorías. Al renombrar, el cambio se aplica a todos los equipos que la usan. Usa "Unificar" para fusionar una categoría en otra.

        Categorías usadas sin registrar

        Equipos que usan una categoría que todavía no está en la lista. Agrégalas para poder renombrarlas y unificarlas.

          Catálogo de supervisores

          Mantenlo ordenado: agrega supervisores una vez y asígnalos a cada registro. Al renombrar, los registros históricos se actualizan automáticamente.

            Asignar supervisor a registros

            Corrige el supervisor de registros ya capturados. Usa el catálogo para mantener el orden.
